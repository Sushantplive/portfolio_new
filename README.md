# Portfolio

Personal portfolio site built with React, TypeScript, Vite, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

## Customize

All personal content (name, bio, projects, skills, social links) lives in
[`src/data/portfolio.ts`](src/data/portfolio.ts) — edit that file to make the
site your own. Sections are split into components under `src/components/`.

## Build

```bash
npm run build
```
